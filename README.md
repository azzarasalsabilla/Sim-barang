# SIM-Barang (Sistem Pengelolaan Inventaris Barang Jurusan)

Proyek ini dikembangkan untuk memenuhi tugas Praktikum Pemrograman Web pada Program Studi D3 Manajemen Informatika, Politeknik Negeri Sriwijaya[cite: 1, 2].

## Konsep Dasar Web (HTTP Request & Response)
* **HTTP Request:** Pesan yang dikirimkan oleh klien (browser) ke server untuk meminta halaman web atau data (contoh metode: `GET` dan `POST`).
* **HTTP Response:** Balasan atau respon yang dikirimkan oleh server kembali ke klien berupa status kode (seperti `200 OK`, `404 Not Found`) beserta dokumen (HTML, CSS, JS).

## Deskripsi Proyek
SIM-Barang adalah aplikasi berbasis web untuk mencatat, mengelola, dan memantau aset/inventaris laboratorium dan jurusan secara terintegrasi[cite: 2].
